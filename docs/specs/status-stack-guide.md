# 仕様書：スタック｜基礎ガイド（pages/status/stack.html）

- 起票：シオン 2026-10-06（JST）／基準 main ebe3667
- 原稿：ネネ「スタック｜基礎ガイド 初稿」（Notion）。公式ルールはゲーム内ヘルプ録画（2026-10-06 18:41）で照合済み
- 図解：夢爽提供の完成品3枚（1672×941）。作り直し・トリミングはしない

## 1. 目的と範囲
- 「スタックとは何か」を初心者向けに説明する基礎ページ。例はイディーネS3「命溢るるカンテラ」の旺花だけ。
- やらない：スタック持ちキャラの一覧、相性、編成、キャラページへの解説追加、スタック用語のキャラページへのタグ付け。

## 2. データ
- 本文の正：`data/status/stack.json`（article 型）。
- 用語：`data/terms.json` に「スタック」を追加（guideUrl = /pages/status/stack.html）。
  キャラページの効果行へのタグ付けは今回しない（将来「スタックとは？」導線を付けるときの受け皿）。

## 3. 原稿からの変更（公式ヘルプとの照合結果）
- 「同じバフ・弱体効果を重ねると、スタック以外は上書き」→ 公式どおり「**同じキャラが**同じ…を重ねた場合」に限定。
  （別のキャラからの同種効果は原則重ね掛けできるため、限定を外すと誤りになる）
- 次段階メモ・状態表示などNotion上の作業用の記述は掲載しない。
- 「旺花」の例は図解に合わせ、{{char}} で黄昏フローレンス・黄金アルトリアのキャラページへリンク。

## 4. 生成の仕組みへの追加（scripts/build-status-guides.mjs）
1. **`{{char:キャラID|表示名}}`**：キャラページ（../characters/<slug>.html）へのリンク。
   キャラ一覧に無いID・ページが無いIDはビルドエラー。
2. **`coverage: { "mode": "examples", "reason": "…" }`**：取りこぼし検査のうち
   「その語を持つスキルを全部参照しているか」だけを外す。「参照したスキルの flow にその語があるか」は残す。
   reason 空欄・mode 違い・ignore 併用はエラー。基礎ガイド専用で、一覧系ページには使わない。
   （「スタック」は 44体・68スキルの flow に出るため、全件参照は基礎ガイドの目的に合わない）
3. ログに「（例のみ・全件検査なし）」を出す（scripts/build-character-pages.mjs の1行）。
- 部品の種類は増やさない（図解3枚は既存の slides を使う）。

## 5. 表示
- 図解：slides 3枚（3.0秒／4.0秒／4.5秒）。配置は「基本ルール → 旺花の節の冒頭」。
  幅・スマホの端まで表示・JS無効時・reduced-motion はカウンタガイドと同じ既存の仕組みのまま。
- 広告：既存の共通ルール（出典の後に1枠 → フッター）。図解直後には出ない。
- 本文の表（1/5/10/15スタック）は残す（図解の文字が読めない場合の代わり）。

## 6. 受け入れ条件
- ビルドが検証NGなしで通る。再ビルドで差分0。poison.html・counter.html は不変。
- 異常系：reason 空欄／ignore 併用／存在しない {{char}} がそれぞれビルドエラーになる。
- stack.html：リンク3本（idyne#skill-3・florence_twilight・artoria_golden）、data-duration 3000/4000/4500、
  広告は出典の後・フッターの前、入口ページとsitemapに1件追加。

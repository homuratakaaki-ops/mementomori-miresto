# 仕様書：状態異常対策キャラ検索（pages/status/countermeasures.html）

- 起票：シオン 2026-10-07（JST）／基準 main 0338ee1
- 依頼：ネネ「状態異常対策キャラ検索ツール 実装依頼」。第1稿（38件）は canonical と全件照合済み

## 1. 照合結果（第1稿 → 正）
- 38件は全て canonical に実在。取りこぼし1件＝トロポンS4（自身の弱体を1つ解除して攻撃者へ付与）。
- 誤り1件＝アイリーンS3の解除対象は「通常攻撃を強化された本人（自身と、自身以外でスピードが最も低い味方）」。
- 6つ目の分類「弱体効果ターン短縮」を新設（夢爽決定）：プリシラS4・ソフィアS3。
- 原文確認（夢爽の録画 10/7）：エレインS3の解除数は2つ → canonical を修正（Lv2の解除は7ターン目以降・自身戦闘不能時は発動しない、も追記）。
  ニーナS2の複数対象時の回数、ユニS2の再発動時の対象は原文にも無いため断定しない表示にした。
- 対象外：バフ無効・敵のシールド全解除（ルークS2、ignore）・ダメージ無効化・武器のステータス欄。
- 計 41スキル・35キャラ。

## 2. データ
- `data/countermeasures.json`（正）。1スキル1件。表示文と検索用の値を分ける。キャラ名・属性・スキル番号・リンクは canonical から生成。
- 検査（ビルド）：根拠の文（evidence）が flow に実在／flow から拾える対策スキルの載せ漏れ0（ignore は理由必須・不要な除外も止める）／
  1スキル1件／未定義の分類・状態異常の禁止。
- 状態異常の候補：毒・出血・浸食・不治・脱力・沈黙・気絶・睡眠・金縛り（スキルデータに実在するもの）。
  行動阻害無効は気絶・睡眠・混乱・沈黙・金縛り、個別状態異常無効は statuses、その他の分類は全ての弱体効果に効く扱い。
  状態異常×対策タイプは「同じ分類の組で両方を満たす」ときだけ当てはまる（解除＋行動阻害無効のスキルが、毒×行動阻害無効に出ないように）。

## 3. 画面
- 上：検索（状態異常・対策タイプ・属性の3つを AND。件数表示。0件時は「○○を『すべて』に戻す（N件）」ボタン）。
- 表は全件をビルド時に出しておき、JS（js/countermeasure-filter.js）は表示の切り替えだけ。JS 無効時は絞り込み欄を出さず全件表示。
- PC は表、幅560px以下は1行＝1枚のカード（既存の guide-table）。カードの下に「このスキルを見る →」（#skill-N へ）。
- 下：状態異常対策の基本（6分類の説明）＋装備：胸アクセサリーの基礎効果が「弱体効果耐性」（夢爽の録画 10/7 22:47、ゲーム内ヘルプ「武具」：部位ごとに基礎効果のステータスが異なる）、専用武器の専用パッシブ効果。
- 状態異常・特殊効果ガイドの一覧の先頭に入口。広告は出典の後に1枠。

## 4. やらないこと
- 効果別辞典・付与キャラ一覧・スタック辞典・編成自動生成・ランキング・複数属性の同時選択。

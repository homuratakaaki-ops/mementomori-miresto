## 3. 生成の仕組みへの追加（scripts/build-status-guides.mjs）
1. 部品 `figure`（静止画1枚）。見た目の幅・狭い画面での広げ方はスライドと同じ（assets/status-guide.css）。
   遅延読み込みなし（本文先頭近くに置くため）。画像の実在・原寸・alt を検査。
2. `related: [{ skillId, reason }]`：その語を含まない関連スキルへのリンクを理由付きで許可。
   理由空欄・その語を含むスキル・本文で使わないスキルはエラー。
3. 数値検査の照合先に、確率（chance）と専用武器の変化（exclusive）の値を追加。
   取りこぼし検査の対象は広げない（既存ガイドの結果を変えないため）。

## 4. 受け入れ条件
- ビルドが検証NGなしで通る。再ビルドで差分0。poison / counter / stack の生成ページは不変。
- 異常系：related の理由空欄／その語を含む related／本文で使わない related／figure の alt 空欄／
  表の確率の書き間違い がそれぞれビルドエラー。
- 図解は「ひとことで」の中、本文の2段落目の直後。広告は出典の後・フッターの前に1枠。

作成日: 2026-10-05 ｜ 作成: ミコト ｜ 状態: **夢爽の確認待ち（JSONにはまだ入れていません）**

キャラ検索を読みで引けるようにするための下書きです。違うものだけ指摘してください。
指摘を反映してから `data/mementomori-skills.json` の `characters[].reading` へ転記します。

## 書き方の決まり

- ひらがなに統一。長音は「ー」、促音・拗音は小書き（っ・ゃ）。検索側で小書きと大書きは同一視します
- `name` は肩書きを除いた名前の読み、`title` は肩書きの読み（肩書きが無ければ省略）
- カタカナ名はひらがなに置き換えただけです（読みが変わらないため）。
  手で読みを決めたのは**英字名2種（A.A. / D.D.）と肩書き25種**だけです
- 英字そのもの（`a.a` など）での検索は、いまの表示名検索がそのまま担います

## 3. 決めてほしいこと（2件）

### (1)「ヴ」の名前をどう書くか

対象は7体：エヴリン / グィネヴィア / オリヴィエ / プリマヴェーラ / リヴェリア / シヴィ / ヴァルリーデ

下書きは表示名どおり「ゔ」で書いています（例：ヴァルリーデ → **ゔぁるりーで**）。
ただし**「ばるりーで」と打つ人は引っかかりません**。「ゔぁ」は変換しないと出ないので、
スマホで探しづらいのは「黄昏」と同じ事情です。案は2つあります。

- **案A（おすすめ）**: 検索側で「ゔ」と「ぶ・ば行」を同一視する。データは表示名どおりのままで、
  「ばるりーで」でも「ゔぁるりーで」でも引ける。データを増やさずに両方拾えます
- **案B**: 読みの方を「ばるりーで」と書く。データだけで済みますが、読みとしては不正確になります

指示が無ければ**案A**で進めます（検索側の正規化を1行増やすだけで、読みデータは下の表のまま）。

### (2) 読みは1キャラ1つだけ

仕様どおり `reading.name` / `reading.title` は1つずつなので、
「せいけんつかい／せいけんづかい」のような揺れは**採った側しか引けません**。
上の「迷った点」で別の読みの方がよければ指摘してください。
両方を引けるようにしたい場合は読みを配列にする必要があるので、別便で相談させてください。

# ガイド図解の作成ルール

2026-10-10 夢爽承認（自傷ダメージガイドの図解で、スマホで文字が小さすぎた反省から作成）。

対象：状態異常・特殊効果ガイドの図解（ネネ作成 → シオン組み込み）

## 1. 作るもの
- **PC用：横長1枚**（今までどおり。16:9、幅1600px以上）
- **スマホ用：テーマごとに縦長1枚ずつ**（PC用の項目数と同じ枚数。例：自傷なら①②③の3枚）
  - サイズ：**縦横比4:5、幅1080px前後**（例：1080×1350、1122×1402）
  - 1枚＝1テーマ。PC用の切り抜きではなく、スマホ用に組み直す

## 2. 文字の大きさ（いちばん大事）
スマホ用は横スワイプの枠いっぱい（画面幅とほぼ同じ、約360px）に縮んで表示されるため、画像上で下の大きさを下回らないこと。

| 種類 | 画像上の文字の高さ（幅1080px基準） | スマホでの見え方 |
|---|---|---|
| 見出し（「① 自分のHPが減る」など） | 72px以上 | 約24px |
| 本文・説明 | 48px以上 | 約16px（本文と同じ） |
| 注記・ラベル（「1回分の例」など） | 36px以上 | 約12px（これより小さくしない） |

- PC用（幅1672px想定、PCで最大960px表示）は、注記でも **28px以上**
- 確認方法：完成画像を **幅360pxに縮小して** 、注記まで無理なく読めるか見る

## 3. 1枚に入れる量
- 文字は **見出し1つ＋説明3行まで** が目安
- 数字・%は本文より大きく
- キャラ名ラベルは1枚につき1〜2人まで

## 4. 余白・はみ出し
- 四辺に **40px以上** の余白。絵や飾りを画像の端ギリギリに置かない（切れて見える）
- 背景は記事の地色になじむ淡い色

## 5. 渡し方
- ファイル名：`<ガイドID>-pc.png`、`<ガイドID>-m1.png`、`-m2.png`…（例：`self-damage-m2.png`）
- 1枚だけ直したいときは、その1枚だけ差し替えて渡せばよい（サイトは1枚単位で差し替えられる）
- PNGで渡す（圧縮・変換はシオン側で行う）

## 6. サイトへの組み込み（シオン側）
- `data/status/<id>.json` の figure ブロック：PC用は `webp`・`webpSmall`（幅960）・`src`、スマホ用は `mobile` に1枚ずつ（`webp`・`src`・`width`・`height`・`alt`）
- `alt` は画像内の文字をすべて文章で書く（スマホ用は1枚ずつ）
- 組み込み前に幅360〜390pxで表示し、2章の大きさを満たすか確認する。満たさない小さな文字は、飾りや繰り返しなら採用してよいが、次回の注意としてネネに伝える
- スマホ用の画像は横スワイプで1枚ずつ送る表示（`js/figure-series.js`）。図は枠いっぱいの幅で出し、ドット・「1 / 3」・前後ボタンと「横にスワイプ」の案内で続きがあることを示す（2026-10-10 夢爽・ネネ決定）
- 画像を差し替えても、ページ側の URL に中身の印（`?v=`）が自動で付くので、古い画像が残る心配はない（`scripts/asset-version.mjs`）

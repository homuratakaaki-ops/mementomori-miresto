# PU履歴の未収録一覧

最終更新: 2026-10-04
対象データ: `data/mementomori-skills.json` の `characters[].pickupHistory`
用途: 出典に日付が無くて入力できなかった回の控え。出典が増えたらここを見て追記する。

---

## なぜ欠けているか

各キャラの `pickupCount`（出典のPU回数）は分かっているが、**回ごとの開催期間は
どの出典にも全部は載っていない**。収録できるのは次の3つだけ。

| 出典 | 取れるもの | 範囲 |
| --- | --- | --- |
| いちごゲームさん 各キャラページ | 実装日（初回＝1回目の開始日） | 全キャラ |
| いちごゲームさん [ガチャ履歴](https://ichigogames.net/mementomori/history/) | 開催期間（開始〜終了）と種別 | 2026-04-08 〜 2026-09-30 の77件のみ |
| いちごゲームさん [復刻待ち日数一覧](https://ichigogames.net/mementomori/pickup_que/) | **直近1回**の開催期間 | 2025-11-27 以降 |

そのため「1回目」と「最終回」は埋まるが、**その間に挟まる復刻が空く**。
アルテマの[ガチャスケジュール](https://altema.jp/mememori/gachaschedule)は突き合わせ用に挙がっていたが、
自動取得が403で拒否されるため未照合。

### 注意: 出典の「直近ピックアップ」列は終了日

各キャラページの「直近ピックアップ」は開催**終了日**で、開始日ではない
（復刻待ち一覧の終了日と97/97体で一致、開始日との一致は0件）。
追記のときに開始日として転記しないこと。

## 現状

- pickupHistory を持つキャラ: **119/119体・201件**
- 全回ぶん日付が揃っているキャラ: **29体**
- 日付が足りないキャラ: **68体 / 未収録 223回**
- リリース組（初回実装のみ・PU実績なし）: **22体**（追記対象外）

リリース組22体は出典でPU回数が「-」でPUの実績が無く、初回実装（2022-10-18）だけを
記録している。PU履歴バッジは出さない。

## 追記のしかた

1. 対象キャラの `pickupHistory` に `{ "date", "endDate", "kind", "round" }` を足す。
2. `round` は実際の回次を入れる（配列の位置ではない）。`kind` は
   1回目=`PU` / 2〜3回目=`復刻` / 4回目以降=`星の導き`。
3. `date` は昇順に並べる。終了日が出典に無ければ `endDate` を省く（空文字は入れない）。
4. 将来の開催予定は入れない（出典の「次回ガチャ」列は使わない）。
5. `node scripts/build-character-pages.mjs` を実行する。
   回次の重複・PU回数の超過・日付の形式・回次と種別の対応は自動で検査される。
6. 埋まったキャラはこの表から消す。

## ゲーム仕様の前提と根拠

| 項目 | 前提 | 根拠 |
|---|---|---|
| 確率・費用・天井 | `GACHA` 定数のとおり（PU 1.37%／天・冥 1.26%・300ダイヤ・100回、運命・星 2.1712%／天・冥 2.0%・500ダイヤ・70回） | 既存値（今回は変更していない） |
| 天井のリセット | 対象キャラが出たらカウント0。ほかのキャラが出ても戻らない | 公式FAQ「ピックアップガチャの確定出現機能」（連続で出なかった回数で判定）、ネネ調査 |
| 天井の単位 | ガチャごと × 属性グループ（通常4属性／天・冥）で別々 | ゲームライン「運命ガチャ」、ネネ調査 |
| 運命と星の導き | 天井を共有しない | 夢爽確認（2026-10-08） |
| チケット | PU・運命・星の導きで別々（ダイヤは共通） | ネネ調査（運命ガチャチケット・星の導きガチャチケットが別アイテム） |
| 運命・星の57回目以降の確率上昇 | **計算に入れない**。上昇はあるが各回の数値が未確認のため。画面とコピーに明記する | ネネ調査（数値の一次情報なし） |

数値が確認できたら、`copyDist` の1回ごとの確率を回数ごとの確率表に置き換える。注意書きも外す。

## 計算

- 1枚ごとの「何回目で出るか」の分布を作る。1回ごとの確率 rate、天井 N 回目で必ず出る。1枚目は現在カウント c から（最大 N−c 回）、2枚目以降は0から。
- 必要枚数ぶんの分布を畳み込み、合計回数 R の分布を作る（`rollDists`、結果はキャッシュ）。
- **平均回数** = E[R]（表示は四捨五入）。
- **平均ダイヤ** = 1回の費用 × E[max(0, R − チケット枚数)]。**ダイヤを計算してから四捨五入する**（払う回数を先に丸めると、少額が0になる。2026-10-08 ネネ指摘）。そのため平均ダイヤは1回の費用の倍数とは限らない。
- **使うチケット（平均）** = E[min(R, チケット枚数)]（表示は四捨五入）。
- **最大（天井保証）** = (N − c) + (必要枚数 − 1) × N 回。チケットを引いた残りに費用を掛ける。
- 併用の最安は、PU p 枚＋運命 d 枚の全振り分けで比べる。平均は四捨五入前の値で比べる。
- 不変条件：平均回数 ≤ 最大回数、平均ダイヤ ≤ 最大ダイヤ。

## 入力と状態

- `state.pity[ガチャ][属性]`、`state.ticket[ガチャ]`、`state.diamond`（1つ）。単独と併用は同じ値を見る。
- ガチャの切り替えで、ほかのガチャの値を書き換えない。
- 入力中（input）は計算だけ更新し、欄の文字は書き換えない。入力が終わったとき（change）に0以上の整数へ直して欄に書き戻す。天井は上限で切り詰める。`Number()` で読むので `1e3` は1000。
- 入力の保存（再読み込みで残す）はしていない。

## 表記

- 「期待値」は使わず「平均（天井込み）」。
- 必要ダイヤ＝チケットを使ったあとに支払うダイヤ（単独・併用とも）。
- 余りカードで足りるときは「目標までの同名カードはそろっています」。進化素材の注意は残す。
- 注意書き（画面・コピー共通、`modelNotes`）：平均は天井での打ち切りを含めること、必要ダイヤの定義、運命・星を含むときは確率上昇を計算に入れていないこと。
